# Getting Started

## Installation

### Install from source

For developers, you can clone the package from Git, then
install the package in editable mode with development dependencies:

```bash
git clone https://github.com/prommis/flowsheet-inspector-lib.git
cd flowsheet-inspector-lib
# set up your Python environment..
pip install -r requirements.dev
```

Source code is in `src` and documentation is in `docs`.

The documentation can be built locally with Sphinx:
```bash
cd docs
sphinx-build . build
```
