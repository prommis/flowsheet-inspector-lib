# Skill Search

This is a thin wrapper for the repository's top-level `skill-search/` helper.

Before acting on the user's request:

1. Read `../../../skill-search/SKILL.md`.
2. Follow that workflow to search `../../../skills/`.
3. Read and follow the matched skill's `SKILL.md`.
